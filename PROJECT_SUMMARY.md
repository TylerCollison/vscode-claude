# Project Summary

AgentDesk is a comprehensive Docker-based development environment that bundles VS Code Server (via linuxserver/code-server), Anthropic's Claude Code AI coding assistant, a LiteLLM-powered multi-provider model router with content-aware routing (images → vision models, web search → search-capable models, complexity-based tiering between fast and reasoning models), and Claude Threads for real-time Mattermost integration — all accessible through a web browser. The image includes management tools (cconx for container lifecycle, build-env for persistent build environments), supports Docker-in-Docker with optional BuildKit acceleration, and provides extensive configuration via environment variables for authentication, API keys (NVIDIA NIM, Google AI Studio, Mistral, Cerebras, OpenCode Zen, EXA AI), Git repository auto-cloning, knowledge repository markdown aggregation, and optional Happier relay server or agent mode for mobile app control. Designed for self-contained, flexible AI-assisted development workflows accessible from any device.
